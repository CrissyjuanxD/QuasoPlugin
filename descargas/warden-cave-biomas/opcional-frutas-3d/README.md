# Frutas colgantes 3D · complemento opcional

Fusiona `assets` con tu resource pack después del pack principal. Conserva tu `pack.mcmeta`.

Este complemento usa modelos de bloque vanilla y **reemplaza globalmente** los froglights verdes/perlados y las enredaderas con bayas, también fuera de Warden Cave. Las enredaderas sin bayas se conservan. No modifica colisión, luz ni drops: los froglights mantienen colisión de cubo completo.

Para desinstalarlo, restaura tus blockstates anteriores de `verdant_froglight`, `pearlescent_froglight`, `cave_vines` y `cave_vines_plant`; si no tenías overrides, elimina los cuatro JSON aportados. El pack principal seguirá aplicando las texturas por bioma con CTM.
